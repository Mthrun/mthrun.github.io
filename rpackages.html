Research Software on CRAN and GitHub

These R packages translate methodological research and interdisciplinary collaborations into reusable software. They support structure discovery and clustering, distribution analysis and visualization, classification and feature selection, time-series forecasting, and computational workflows. Most packages are available on CRAN; development versions and specialized tools are hosted on GitHub. Each package has its own license; some GitHub packages are restricted to noncommercial use.

For company-specific applications, I develop and integrate AI methods through IAP-GmbH Intelligent Analytics Projects, from feasibility studies to prototypes and MVP deployment. See selected projects and applications.

For reproducible use, please consult the package documentation and cite both the software and the associated methodological publication where applicable.
