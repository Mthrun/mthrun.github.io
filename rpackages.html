Research Software on CRAN and GitHub

These open-source packages translate methodological research and interdisciplinary collaborations into reusable software. They support structure discovery and clustering, distribution analysis and visualization, classification and feature selection, time-series forecasting, and computational workflows. Most packages are available on CRAN; development versions and specialized tools are hosted on GitHub.

For reproducible use, please consult the package documentation and cite both the software and the associated methodological publication where applicable.
